# Security policy

Do not use FarmShield AI with real personal or farm data until it has received an appropriate security and privacy review.

For a suspected vulnerability, do not publish credentials, private images, or exploit details in a public issue. Contact the repository maintainers privately with a summary, affected version, and reproducible impact. Rotate any exposed credentials immediately.

Development defaults are not production-ready. See [`docs/security.md`](docs/security.md) for the token model, upload handling, deployment limitations, and required production configuration.
