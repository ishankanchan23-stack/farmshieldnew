# Contributing

Thanks for helping improve FarmShield AI. This project is a learning prototype; contributions must preserve clear model and weather limitations.

1. Open an issue for substantial changes and explain the user impact.
2. Work on a focused branch and avoid including credentials, private images, model weights, or local database files.
3. Add or update tests for behavior changes. Run backend `python -m pytest` and frontend `npm test`, `npm run build`, and `npm run lint` when relevant.
4. Keep API schemas synchronized with the TypeScript client and document configuration changes.
5. Submit a pull request with a concise summary, testing performed, and screenshots for UI changes.

Do not describe educational or unvalidated outputs as confirmed diagnoses, performance claims, or treatment advice.
